# 04-react-query

A React application that uses React Query to fetch movies from The Movie
Database (TMDB) and display them in a grid.

## Installation

1. Clone the repository using
   `git clone https://github.com/username/04-react-query.git`
2. Install dependencies using `npm install`
3. Start the development server using `npm start`

## Features

- Fetches movies from TMDB using React Query
- Displays movies in a grid
- Allows the user to search for movies
- Displays a modal with more information about the movie when the user clicks on
  it
- Uses React Hot Toast to display a loading message when fetching movies
- Uses React Paginate to paginate the results

## Technologies Used

- React
- React Query
- React Hot Toast
- React Paginate
- The Movie Database (TMDB) API
